03. Part B: Model Answers to Discussion Questions
1. Which extension changed your day-to-day typing/editing experience the most?
Prettier. Enabling format-on-save in VS Code completely eliminated manual indentation and formatting friction. Developers can rapidly draft logic without pausing to format braces or align tag nesting, trusting the AST formatter to clean up the code upon save.
2. Which extension is about the code itself vs. about collaboration/history?
Python, Java, and Prettier are directly about code correctness, syntax trees, static analysis, and aesthetics. In contrast, GitLens and Live Share are team meta-layer tools—GitLens surfaces historical context (author, commit date, reason), while Live Share enables synchronous co-authoring across distributed engineers.
3. Which extension would you keep enabled globally vs. language-specifically?
Prettier and GitLens should remain globally active across all projects because formatting standards and commit history are universal. Python and Java packs should be restricted to their respective workspaces to conserve memory and avoid heavy background language server daemons when opening non-target files.
4. How did Live Share change the feeling of pair programming compared to screen sharing?
Screen sharing is passive and asymmetric—only the presenter controls navigation while the partner watches. Live Share empowers both engineers with independent cursor focus, simultaneous multi-file editing, and shared terminals, converting a passive spectator experience into an active engineering partnership.
